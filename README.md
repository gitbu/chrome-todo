# Todo Manager - Chrome 扩展

一个功能完整的待办事项管理Chrome扩展，支持项目分组和数据统计。

## ✨ 功能特性

- ✅ **待办事项管理**: 完整的增删改查功能
- 📁 **项目分组**: 创建项目（事物），在项目下管理待办事项
- 📊 **数据统计**: 首页显示总任务数、未完成数和已完成数
- 🎨 **美观界面**: 现代化的渐变色设计
- 💾 **本地存储**: 使用Chrome Storage API，数据安全可靠
- 🔄 **双视图模式**: 项目视图和全部任务视图自由切换

## 📸 功能预览

### 主要功能

1. **项目管理**
   - 创建/编辑/删除项目
   - 查看每个项目的任务统计
   - 点击项目进入详情

2. **待办事项管理**
   - 在项目下添加待办事项
   - 标记完成/未完成
   - 编辑任务内容
   - 删除任务

3. **数据统计**
   - 实时显示总任务数
   - 未完成任务数（高亮显示）
   - 已完成任务数

## 🚀 安装使用

### 方法一: 开发者模式加载（推荐）

1. 克隆或下载此项目到本地
   ```bash
   git clone <repository-url>
   cd chrome-todo
   ```

2. 生成更好看的图标（可选）
   - 在浏览器中打开 `icons/generate-icons.html`
   - 点击下载按钮，将生成的图标保存到 `icons/` 目录，替换现有的占位符图标

3. 打开Chrome浏览器，进入扩展管理页面
   - 地址栏输入: `chrome://extensions/`
   - 或通过菜单: 更多工具 -> 扩展程序

4. 开启**开发者模式**（右上角开关）

5. 点击**加载已解压的扩展程序**

6. 选择本项目的文件夹

7. 扩展安装成功！点击浏览器工具栏的扩展图标即可使用

### 方法二: 打包安装

1. 在扩展管理页面点击**打包扩展程序**
2. 选择项目目录进行打包
3. 将生成的 `.crx` 文件拖入Chrome进行安装

## 💡 使用说明

### 创建项目

1. 在"项目视图"下
2. 在输入框中输入项目名称
3. 点击"+ 添加项目"按钮

### 添加待办事项

1. 点击某个项目进入详情
2. 在输入框中输入待办事项内容
3. 点击"+ 添加"按钮或按回车键

### 管理待办事项

- **标记完成**: 点击待办事项前的复选框
- **编辑**: 点击待办事项右侧的编辑按钮（✏️）
- **删除**: 点击待办事项右侧的删除按钮（🗑️）

### 管理项目

在项目详情页面的标题栏：
- **编辑项目**: 点击编辑按钮（✏️）
- **删除项目**: 点击删除按钮（🗑️）
- **关闭**: 点击关闭按钮（✖️）

### 查看所有任务

点击"全部任务"视图切换按钮，可以查看所有项目的所有待办事项。

## 🔐 隐私说明

- 所有数据存储在本地，使用Chrome的本地存储API
- 不会上传任何数据到服务器
- 不会收集任何用户信息

## ❓ 常见问题

**Q: 数据会丢失吗？**
A: 数据存储在Chrome本地存储中，除非手动清除浏览器数据或卸载扩展，否则不会丢失。

**Q: 可以同步到其他设备吗？**
A: 当前版本使用本地存储，不支持同步。未来版本可能会添加云同步功能。

**Q: 如何备份数据？**
A: 可以在Chrome的扩展管理页面导出扩展数据，或者未来版本会添加导出功能。
