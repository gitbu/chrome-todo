# Todo Manager - Chrome 扩展

一个类似 TickTick 的现代化待办事项管理Chrome扩展，采用三栏布局设计，支持标签分类、日期管理和详细备注。

## ✨ 核心功能

### 📝 待办事项管理
- ✅ 完整的增删改查功能
- ✏️ 详细的备注编辑
- 📅 截止日期设置
- ☑️ 完成状态标记
- 📁 列表/项目分类管理
- ⭐ 优先级设置（高/中/低/无）
- 🔍 搜索功能
- 👁️ 显示/隐藏已完成任务

### 🎨 三栏布局设计
- **左侧导航栏**：智能列表、自定义列表/项目
- **中间列表区**：待办事项列表展示、搜索、筛选
- **右侧详情面板**：待办事项详细编辑、子任务管理

### 📊 数据统计
- 总任务数量
- 未完成任务数（高亮显示）
- 已完成任务数
- 今天的任务数

### 📁 列表/项目系统
- 创建自定义列表
- 支持层级结构（文件夹式组织）
- 颜色标识
- 按列表筛选
- 列表任务统计

### ⭐ 优先级系统
- 四个优先级：高🔴、中🟡、低🔵、无
- 颜色边框标识
- 优先级图标显示
- 一目了然的视觉反馈

### 📅 智能列表
- **首页**：显示所有待办事项
- **今天**：显示今日截止的任务
- **明天**：显示明日截止的任务
- **接下来7天**：显示未来7天内的任务
- 实时统计各列表任务数量
- 过期任务高亮提醒
- 友好的日期格式（今天、明天、具体日期）

### 🔍 搜索与筛选
- 实时搜索任务标题和备注
- 显示/隐藏已完成任务
- 快速清除搜索

### ✅ 子任务系统
- 支持无限层级子任务
- 子任务展开/折叠
- 递归进度计算
- 内联添加子任务

## 🚀 安装使用

### 安装步骤

1. 克隆或下载此项目到本地
   ```bash
   git clone <repository-url>
   cd chrome-todo
   ```

2. 打开Chrome浏览器，访问扩展管理页面
   - 地址栏输入: `chrome://extensions/`
   - 或通过菜单: 更多工具 -> 扩展程序

3. 开启右上角的 **开发者模式**

4. 点击 **加载已解压的扩展程序**

5. 选择本项目的文件夹

6. 安装完成！点击浏览器工具栏的扩展图标即可打开

## 📖 使用指南

### 基本操作

#### 添加待办事项
1. 在中间列表区域的输入框中输入待办事项标题
2. 按回车或点击"添加"按钮
3. 点击待办事项可在右侧查看和编辑详情

#### 编辑待办事项
1. 点击任意待办事项打开右侧详情面板
2. 可以编辑：
   - 标题
   - 完成状态
   - 标签
   - 截止日期
   - 备注

#### 管理标签
1. 点击左侧导航栏"标签"区域的"+"按钮
2. 输入标签名称
3. 系统自动分配颜色
4. 点击标签可查看该标签下的所有待办

#### 查看今天的任务
1. 点击左侧导航栏的"今天"
2. 显示所有截止日期为今天的待办事项
3. 在此视图下添加的待办会自动设置日期为今天

### 快捷技巧

- **快速标记完成**：直接点击待办事项前的复选框
- **快速添加**：输入框支持回车键快速添加
- **自动保存**：详情面板中的编辑会自动保存
- **智能排序**：未完成的任务自动排在前面

## ❓ 常见问题

**Q: 如何备份数据？**
A: 当前版本数据存储在Chrome本地存储中。未来版本会添加导出/导入功能。

**Q: 数据会丢失吗？**
A: 数据存储在Chrome本地，除非手动清除浏览器数据或卸载扩展，否则不会丢失。

**Q: 可以同步到其他设备吗？**
A: 当前版本使用本地存储。未来版本可能会添加云同步功能。

**Q: 如何更改标签颜色？**
A: 当前版本标签颜色是随机分配的。未来版本会支持自定义标签颜色。

**Q: 支持快捷键吗？**
A: 当前版本暂不支持快捷键。未来版本会添加快捷键支持。
